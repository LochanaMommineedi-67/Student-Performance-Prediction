# 🎓 Student Performance Prediction using Machine Learning

### 📌 Project Overview
This project uses academic and demographic features to predict a student's final grade (**G3**) using machine learning models. The analysis helps identify students requiring early academic support.

---

### 🧠 Objective
- Analyze factors affecting student academic performance
- Apply machine learning to predict **final exam scores**
- Provide insights for student improvement

---

### 🛠️ Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

---

### 📂 Dataset Information
- Dataset used: **Student Performance Dataset (UCI Repository)**
- Includes:
  - Previous grades (**G1, G2**)
  - Study time, absences, parental support
  - Demographic & social factors

📌 Dataset link:  
🔗 https://archive.ics.uci.edu/ml/datasets/Student+Performance

---

### 🧪 Machine Learning Models Used
- Linear Regression (Primary Model)
- Compared with models like:
  - Random Forest Regressor *(optional)*
  - Decision Tree Regressor *(optional)*

---

### 📊 Workflow
1. Data loading & cleaning  
2. Exploratory Data Analysis (EDA) & feature correlation  
3. Feature selection (G1, G2, etc.)  
4. Model training & testing  
5. Evaluation using R² Score / MSE  

---

### 🔍 Key Insights
- G1 and G2 scores have the **strongest influence** on G3  
- Students with higher study time tend to score better  
- Irregular attendance → performance drops  
- Social and family support also contribute

---

### 🚀 Results
- Built a model that **accurately predicts final grade (G3)**  
- Delivered actionable insights for student improvement tracking
